# Minicamp Dev & Data — XPe

Exercícios e projetos realizados no Minicamp Dev & Data da XPe.

## Organização

- `Semana I/`: Exercícios e desafios iniciais.
- `Semana II/projeto2/`: Projeto web com HTML, CSS e JavaScript.

## Como estudar e executar

Requisitos: navegador moderno. Para servir os exemplos localmente, Python 3.

```sh
git clone https://github.com/FilipeBandeira/minicamp.git
cd minicamp
python3 -m http.server 8000
```

Abra `http://localhost:8000/Semana%20II/projeto2/index.html` ou navegue pelas pastas no servidor. Leia o código de cada exemplo, execute-o e compare o comportamento com o assunto estudado.

## Escopo

Os arquivos são exemplos independentes de estudo; não constituem uma aplicação integrada. Este repositório preserva a trajetória de aprendizado e os créditos dos materiais originais.
